# Third-party skills

The skills in this directory (`banner-design`, `brand`, `design`,
`design-system`, `slides`, `ui-styling`, `ui-ux-pro-max`) are vendored
from the [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
repository by Next Level Builder, version 2.13.0, for use as Claude Code
project skills in this repository.

Licensing:

  (see the upstream repository's `LICENSE` file).
- `ui-styling` is Apache-2.0 licensed (see `ui-styling/LICENSE.txt`).

These are general-purpose UI/UX design skills (color palettes, typography,
layout, charts, accessibility, banners, slides, brand systems) and are not
specific to the ZINARA JEWELRY Shopify theme built in this repository.
