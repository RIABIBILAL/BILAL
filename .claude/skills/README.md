# Third-party skills

The skills in this directory (`banner-design`, `brand`, `design`,
`design-system`, `slides`, `ui-styling`, `ui-ux-pro-max`) are vendored
from the [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
repository by Next Level Builder, version 2.13.0, for use as Claude Code
project skills in this repository.

Licensing:
- All skills except `ui-styling` are MIT-licensed by Next Level Builder
  (see the upstream repository's `LICENSE` file).
- `ui-styling` is Apache-2.0 licensed (see `ui-styling/LICENSE.txt`).

These are general-purpose UI/UX design skills (color palettes, typography,
layout, charts, accessibility, banners, slides, brand systems) and are not
specific to the ZINARA JEWELRY Shopify theme built in this repository.

## OmniRoute API-reference skills

The `cli-*`, `omni-*`, `config-codex-cli`, and `ponytail` skills are vendored
from the [OmniRoute](https://github.com/diegosouzapw/OmniRoute) repository
(MIT-licensed, Copyright (c) 2026 diegosouzapw). OmniRoute is a self-hosted
AI gateway/router application; these `SKILL.md` files are its own
auto-generated REST API reference docs (generated by
`src/lib/agentSkills/generator.ts` in that repo), describing endpoints on a
*running OmniRoute server* (e.g. `https://localhost:20128/api/...` with an
`OMNIROUTE_TOKEN` bearer token).

**They are reference material only** — they do not do anything on their own
and are not connected to any OmniRoute instance from this repository or
this Shopify theme. They're only actionable if you separately deploy
OmniRoute and provide its API base URL and token. They are unrelated to the
ZINARA JEWELRY theme.

## 21st-ui skill (21st.dev / magic-mcp)

`21st-ui` is vendored from
[github.com/21st-dev/magic-mcp](https://github.com/21st-dev/magic-mcp)
(ISC-licensed, Copyright (c) 2026 21st.dev). It's a workflow guide for the
**21st MCP** — a live UI-component marketplace (search/install/generate
React+Tailwind components) reached over the MCP server wired up in this
repo's `.mcp.json`.

Unlike the other vendored skills above, this one needs a real, authenticated
MCP connection to do anything: `.mcp.json` points at
`https://21st.dev/api/mcp` with the API key read from the `API_KEY_21ST`
environment variable — **no key is stored in this repository**. Get a free
key at [21st.dev/mcp](https://21st.dev/mcp) and set `API_KEY_21ST` in
whatever environment runs Claude Code against this repo (shell profile,
Claude Code's environment-variable settings, or your CI secrets — never
committed to git). Without it, the `21st` MCP server will fail to
authenticate and the skill's tools (`search`, `get_component`, `generate`,
`search_logo`, etc.) won't be available. Unrelated to the ZINARA JEWELRY
theme.
